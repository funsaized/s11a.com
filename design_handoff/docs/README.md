# Coffee & Code — System Documentation

Documentation for the s11a "Coffee & Code" design system, organized with the [Diátaxis framework](https://diataxis.fr/): four modes of documentation, each serving a distinct user need.

| | **Serve learning** | **Serve work** |
|---|---|---|
| **Practical steps** | [Tutorials](./tutorials/) — learn by building | [How-to guides](./how-to/) — accomplish a task |
| **Theoretical knowledge** | [Explanation](./explanation/) — understand the why | [Reference](./reference/) — look up the facts |
